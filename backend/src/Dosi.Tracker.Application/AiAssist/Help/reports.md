---
title: Reports and what they show
keywords: report, reports, export, csv, summary, attendance, devices, apps, weekly, analytics
---
The Reports page offers several views: a time and activity overview, a weekly breakdown, per-project totals, a productivity (activity %) view, an apps and URLs view, attendance, devices, and a combined analytics view. Which of these a manager can see depends on the reporting permission an owner has granted them; members usually see only their own figures, if anything.

Every report can be filtered by date range and, where relevant, by project or member, and exported as CSV or JSON for use elsewhere. An export always matches what the on-screen report shows for the filters you had selected.

Attendance reports count days a member had any tracked time against days they had none, over working weekdays since they joined the workspace; it does not know about approved leave or holidays unless your workspace records those separately. Devices reports show which platform and agent version each member's device last reported, which helps catch an out-of-date agent, but never the device's name or operating system version.

Figures shown as "not measured" mean the project did not collect that figure (for example, activity percent on a project with input measurement turned off) - treat it as unknown, never as zero.

Ask AI can explain any of these pages in plain language for the range you are viewing, and can describe a period or a single member's day, but it always works from the same numbers the page itself shows, never from anything else.
