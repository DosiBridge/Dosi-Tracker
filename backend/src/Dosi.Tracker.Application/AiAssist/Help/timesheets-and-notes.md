---
title: Timesheets and adding notes
keywords: timesheet, note, notes, edit, block, activity, description, task
---
Your tracked time appears on the Timesheet (or Activities) page as a series of blocks, each with a start and end time, the project it was tracked against, and, where the project allows it, which apps had focus and for how long.

You can add a short note to one of your own blocks to describe what you worked on, as long as it is still inside the workspace's note-editing window after it was tracked (commonly a number of days; ask a manager for your workspace's exact limit). A manager with the right permission can also add or edit a note on another member's block, and can usually do so for longer, to help clean up timesheets before a report is sent out.

Notes are plain text and are meant to describe the work, not to contain sensitive information: avoid putting passwords, client secrets or personal data for someone else into a note, since managers and (if your workspace allows it) Ask AI may both read it.

If a block looks wrong — the wrong project, a time that is clearly off, or activity you did not do — add a note explaining it and flag it to a manager; blocks themselves are not editable by members beyond adding a note, to keep the underlying tracked record trustworthy.

Ask AI can suggest a short note for a block, based on the project, the apps that were active, and any earlier note on a similar block of yours, but it never invents facts: it only ever offers wording you can accept, edit or ignore.
